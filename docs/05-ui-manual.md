# UI 用户手册与页面规范

## 全局 UI

- Vue 3 + Naive UI。
- 使用 SCSS。
- 使用 `unplugin-auto-import` 自动导入 Vue、Vue Router、Pinia 和常用 composables。
- 使用 `unplugin-vue-components` 自动导入 Naive UI 组件和本地通用组件，减少重复 import。
- 设计 token 放全局样式，组件私有样式放 scoped SFC。
- 不随意覆盖 Naive UI 默认圆角等基础风格。
- 优先组合 Naive 组件，不手写大量结构。
- 默认分页 50。
- 能用图标提升识别度的地方尽量使用图标，例如导航、操作按钮、solved、状态、时间、内存、标签、筛选和管理入口。

## 导航

顶级：

- 首页
- 题库
- 作业
- 比赛
- 讨论
- 排行
- 提交
- 管理

显示规则：

- 作业仅登录显示。
- 管理仅 admin 显示。
- 提交列表可公开显示裁剪后的提交。
- 访客公开内容由 `general.guestAccess` 控制。

## 首页

布局：宽屏三栏 + 热力图。

三栏：

- 推荐题目：未 AC 题目。
- 我的作业：完成/未完成都显示。
- 近期比赛：未结束比赛。

热力图：

- 类似 GitHub 全年提交热力图。
- 可放三栏上方或下方，以视觉效果为准。
- 不要设计成后台 dashboard。
- 未登录时不请求或收到 401 后显示登录提示，不用空数组伪装个人数据。

站点公告：

- 如果 `general.notice` 为空，不展示。
- 如果不为空，在首页以轻量方式展示。

## 题库列表

展示：

- solved 图标。
- 题号。
- 标题。
- 标签。
- 通过率。
- 管理员编辑入口。

交互：

- 搜索范围固定为题号、标题和标签，大小写不敏感。
- tag 筛选。
- 分页 50。

## 题目详情

布局：

- 上部题面与元信息，可宽屏左右分栏。
- 左侧题面。
- 右侧限制、通过率、标签、最近我的提交。
- 底部整宽提交区域，代码编辑器需要宽。

题面：

- 使用 Markdown 编辑器的 read-only/preview 渲染能力。
- 不能显示工具条、行号、编辑器边框等编辑器痕迹。

提交：

- 未登录显示登录提示。
- 登录后选择语言、编辑代码、设置源码是否公开并提交。
- 源码公开勾选框初始值来自 `general.publicCode`，用户可修改。
- 默认语言为 `cpp`。

## 提交列表

展示：

- 状态。
- 题目。
- 用户。
- 语言。
- 时间。
- 内存。
- 分数。
- 创建时间。

交互：

- 分页 50。
- status/problem/user/language/context 筛选。
- WebSocket 更新当前页中 WAITING/JUDGING 提交状态。

## 提交详情

展示：

- 状态、分数、时间、内存。
- 运行中 progress。
- 源码或受限提示。
- 判题消息。
- 测试点结果。
- AI coaching 按钮。

测试点：

- 超过 50 时分页或折叠。
- 运行中通过 WebSocket 展示 per-case 摘要。
- 完成后读取最终 cases。

## 排行

展示：

- 排名。
- 头像。
- 用户名。
- AC 数。
- 提交数。

数据来自 Redis 派生统计，允许不强实时。

## 作业

我的作业列表：

- 分页 50。
- 展示标题、时间窗口、完成概况。

作业详情：

- 展示题目列表、每题状态、attempts、best score/AC、last submission。
- 题目点击进入统一题目详情。

## 比赛

列表：

- 分页 50。
- 筛选当前、即将、历史。
- 展示赛制、开始、结束。

详情：

- 固定 tabs：题目、榜单、提交。
- 未开始普通用户不看题目列表。
- 封榜后管理员操作文案为“查看真实榜单”。

## 讨论

列表：

- 分页 50。
- 展示标题、作者、tags、更新时间、置顶。
- 排序固定为置顶优先，其次按更新时间倒序；新回复会刷新 topic 更新时间。

详情：

- 展示首楼和回复。
- 首版可不做编辑/删除。
- 不支持站内图片上传，可使用站外图片链接。
- 题目详情可按 tag 展示相关讨论。

## Profile

展示：

- Gravatar 头像。
- 用户名。
- 邮箱。
- 简介。
- 修改密码。
- 修改邮箱。

修改邮箱：

- 需要邮件验证码。
- 邮件未配置时功能不可用并给出明确提示。

## 管理端结构

管理菜单：

- 通用
- 成员
- 题目
- 作业
- 比赛
- 语言
- 评测机

### 通用

子 tab：

- 基础：站点公告、开放注册、代码默认对他人可见性、游客可访问公开内容。
- 邮件：SMTP。
- AI：OpenAI-compatible 配置。

不做站点标题。

### 成员

Users：

- 分页 50。
- 创建用户。
- 编辑用户名、邮箱、简介、admin、disabled。
- 重置密码。

Groups：

- 创建/改名/删除。
- 添加成员使用弹框搜索。
- 支持移除成员。
- 不做 group manager。

### 题目

题目列表：分页 50。

创建/编辑流程：

1. 基础信息：标题、限制、标签、可见性；创建时 content 可为空，先拿 ID。
2. 题面与附件：编辑 Markdown，上传 `assets/{filename}`，附件平铺。
3. 数据与评测资源：上传 `data/{filename}` 和根目录 `Dockerfile`、`checker.cc` 等。

资产分区：

- 数据：`data/`。
- 附件：`assets/`，不允许子目录。
- 评测资源：根目录文件，例如 Dockerfile、checker.cc。

不做树形编辑器，不把根目录所有文件一股脑展示给用户。

备注：未来可做渐进式编辑，把题目管理能力下沉到题目列表和题目详情。

### 作业管理

- 列表分页 50。
- 创建后立即生效，截止前可编辑结构字段，截止后只允许编辑标题和描述。
- 选择 groups 和 individual users。
- 选择 problems。
- 查看报告。
- 删除为软删除。

### 比赛管理

- 列表分页 50。
- 创建/未开始编辑。
- 选择题目并自动分配 A/B/C key。
- 不配置每题分值。
- OI 不展示封榜时间字段，保存为 `NULL`。
- ICPC 展示封榜时间字段，创建时默认预填 `endAt - 1h`，管理员可改；清空表示不封榜。
- 可查看真实榜单。
- 删除为软删除。

### 语言管理

- 列表可不分页。
- seed 默认 `cpp`，source 为 `main.cc`。
- 其他语言 source 由管理员填写。
- Dockerfile 文本编辑。
- 不允许删除最后一个语言。

### 评测机

展示：

- 在线 Agent。
- name/key。
- concurrency。
- active jobs。
- version。
- connectedAt。
- lastHeartbeat。
- 接入指引。

不展示 labels。不做 token rotate。不保存 PG agent。

## Markdown 编辑器

固定使用 `md-editor-v3`。

要求：

- Vue 3 支持。
- 所见即所得或接近所见即所得。
- 工具条。
- 源码模式。
- read-only/preview。
- 自定义图片上传。
- 可禁用上传。
- 展示态无编辑器痕迹。

题目编辑可上传站内图片到 `assets/`；讨论不上传站内图片。
